# Les Bons Choix — site d'affiliation

Site simple (HTML/CSS/JS) qui affiche des produits avec tes liens affiliés.

- `assets/produits.js` → **le seul fichier à modifier** (nom, prix, image, lien affilié).
- `mentions-legales.html` → remplace `[TON NOM]` et `[TON EMAIL]`.

Mise en ligne gratuite : GitHub → Settings → Pages → Branch `main` → Save.
